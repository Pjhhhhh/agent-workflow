## 命令参考逐句判断用途

材料：虚构命令 `pinebox archive` 把源目录归档到目标文件。`--source <path>` 和 `--output <path>` 必填；`--format` 可选 `zip`、`tar`，默认 `zip`。源目录须可读，输出文件的父目录须可写。中断后会留下 `<output>.part`，再次执行会覆盖该文件；重试前须确认进程已结束并保留其中需要的数据。任务材料另含“命令与参数已逐项核对”的编辑记录；旧设计记录说明，维护者曾使用手工操作完成归档。

任务：整理供使用者查询的当前命令参考。

改写前：本节只说明当前归档命令，不涵盖所有归档场景。维护者已逐项核对命令与参数，此前使用手工操作完成归档。

```text
pinebox archive --source <path> --output <path> [--format zip|tar]
```

`--source` 和 `--output` 必填；源目录须可读，输出文件的父目录须可写。`--format` 可选 `zip`、`tar`，默认 `zip`。该命令不提供所有文件格式转换能力。中断后会留下 `<output>.part`，再次执行会覆盖该文件；重试前须确认进程已结束并保留其中需要的数据。

改写后：将源目录归档到目标文件：

```text
pinebox archive --source <path> --output <path> [--format zip|tar]
```

| 参数 | 用法 |
| --- | --- |
| `--source <path>` | 必填，指定可读的源目录。 |
| `--output <path>` | 必填，指定目标文件，父目录须可写。 |
| `--format` | 可选 `zip`、`tar`，默认 `zip`。 |

中断后会留下 `<output>.part`，再次执行会覆盖该文件。重试前确认进程已结束，并保留其中需要的数据。
