# 既有文件、模板与交付检查

## 原件与编辑基线

编辑前保留必要的原模板和当前编辑前副本。原模板用于核对受保护的标题、标签、评分说明、定义、枚举、结构与格式；当前副本用于核对本轮增量，以用户当前文件为基线，保留用户已有修改。

按用户原话及有效纠正确定可改范围与受保护部分，区分明确限制、参考样例与执行者的解释，在已有编辑记录中写明需要核对的内容。填写、完善或替换内容按指定字段与范围进行；重建模板、转换格式、采用参考样式或美化排版须属于本次要求。采用参考材料的内容时，审批、演练、达标等业务状态依据本项目实际记录填写。

## 文件属性与编辑方式

核对编辑工具能否保留受保护属性，选择相应编辑方式。编辑既有文件时，默认保留文件类型、工作表及章节顺序、栏目、样式、公式、验证规则、隐藏状态、合并区域与打印设置，仅调整任务要求或已获准的部分；文本文件保留编码、换行及任务以外的空白格式。新增记录采用同类原行的获准格式，新建文件按任务选择版式。

## 局部版式适配

内容超出原区域时，先在原区域内调整。自动适配或显示修复采用现有范围内的可逆局部修改，保留业务含义、字体底色、栏目公式、整体风格与文件类型，按用户原话执行明确限制。行距、标题或表头同页、重复显示等技术细节按已确定的适配范围处理，核对受影响内容与分页。

原属性与必要显示结果发生冲突，且现有要求未确定取舍时，说明保留原属性的后果及局部适配的具体差异，确认该项取舍。执行者造成的超范围内容、结构或样式变化，按源模板或获准版本恢复，保留已批准的填写结果。

## 保存与交付检查

实际保存后重新打开最终文件，检查内容可读、文件可编辑；有版式要求时，查看或渲染实际页面。按影响范围检查工作表、栏目、公式、合并、样式、页眉页脚与分页，格式对照采用实际文字的有效属性。对照原模板核对受保护部分，对照编辑前副本核对本轮差异及其要求依据；对照不足的部分保留待验证状态。

交付前查看实际目录，确认源模板、历史交付和本次结果各自的用途，以及当前有效文件的位置。修订沿用约定路径与命名。源模板和旧交付分别按用途确定保留方式；替换、改名、移动或归档按精确范围执行并核对目标，待确认的既有文件保留原处。
