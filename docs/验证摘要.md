## 受控任务样本

原生 Codex 受控样本覆盖维护项目外普通问答、项目内只读审查、代码与文档修改、用户纠正和途中问题后的续接。样本中的动作与文件结果符合对应要求，代码修改通过夹具已有 3 项检查。输入条件与观察对象见[五类过程检查](真实任务检验.md#全局规则的五类实际过程检查)。

工程方法与验证方法的选用有三类受控读取样本：简单文档修订，按规格实施与故障诊断，应用验证维护及性能比较。该结果支持入口与方法选择的可达性，真实任务的总体收益继续按模型对照实验检验。
