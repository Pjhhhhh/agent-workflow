# 任务分诊标签

工程技能中的五个分诊角色与本项目的标签保持同名。本地任务在 `Status:` 行记录对应标签。

| 技能角色 | 本项目标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待提出者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由代理执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不予处理 |

技能提到某个分诊角色时，使用表中对应标签。后续需要调整词汇时，修改“本项目标签”列。
