# 依据与适用范围

核对日期：2026-09-30。以下记录本项目采用的流程方法、来源及使用条件。

## 作者与官方方法

| 一手来源 | 采用的方法与条件 |
| --- | --- |
| [Karpathy autoresearch，锁定提交 program.md](https://github.com/karpathy/autoresearch/blob/068d93da75aa45f72ba482046f108241aaaf1b8e/program.md) | 原场景是训练指标优化；借用固定评测器、基线和实验记录，将工作对象与验收规则分开。本地实验采用明确的结束条件 |
| [吴恩达，Evals and Error Analysis Part 1，2025-10-15](https://www.deeplearning.ai/the-batch/improve-agentic-performance-with-evals-and-error-analysis-part-1/) | 从真实输出的错误建立客观与主观指标，迭代 eval，同时完成用户明确要求的验收 |
| [吴恩达，Part 2，2025-10-22](https://www.deeplearning.ai/the-batch/improve-agentic-performance-with-evals-and-error-analysis-part-2/) | 沿 trace 查找错误位置，检查任务分解；根据效果证据调整步骤，模型升级后重新评估原有编排 |
| [OpenAI evaluation best practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices) | 采用任务特定目标、实际输入分布、运行记录、人工校准和持续比较 |
| [Anthropic Demystifying evals for AI agents](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents) | 区分过程记录与环境终态，按任务组合代码、模型和人工检查；模型评委先校准，完成情况核对实际环境结果 |
| [Lance Martin，Automating eval design and hillclimbing with Claude，2026-09-28](https://claude.dev/blog/automating-eval-design-and-hillclimbing/) | 按真实任务设计检验，校准评审，固定运行条件，每次改变单个因素，使用保留集检查噪声与过拟合 |
| [OpenAI 长任务说明](https://learn.chatgpt.com/docs/long-running-work) | 按用户明确要求选择宿主长任务入口，继续依据当前任务要求验收结果 |

[Anthropic Building effective agents](https://www.anthropic.com/engineering/building-effective-agents)提供 evaluator-optimizer 模式与从简单方案开始的建议。本项目使用已有子代理作只读复核；评估复核效果时，另行检查观察与错误统计的独立性。

## 两篇评论文章怎样采用

《Loops and Graphs》和《Harness Engineering》的文本副本将局部修复循环、依赖组织、工具、持久状态和观察分别解释，作为流程设计的启发。文章提出“一个节点失败只返修该节点”和“重要规则有机器检查”，可据此设计实际问题的检验。

需要整理依赖时，使用工作图；反复失败时，根据失败证据重新诊断。改进记录保留适用条件，由多次真实案例判断是否形成长期规则。

本文采用所提供的正文副本，编辑时间未确认；原始来源为 [Loops and Graphs](https://x.com/hanakoxbt/status/2091515787366306154) 和 [Harness Engineering](https://x.com/0xwhrrari/status/2093685107534000560)。

pstack 与 HumanLayer 的工程方法包括重复调用的验证入口、明确的测量与下一动作、具体条件下读取资料，以及单一规则来源。具体采用方式与来源见[流程参考与取舍](流程参考与取舍.md)、[pstack 验证技能](https://github.com/cursor/plugins/blob/fae2c6ed95821bd85f614a73e4842e13229fa5e5/pstack/skills/create-verification-skill/SKILL.md)和 [HumanLayer 控制循环设计](https://github.com/humanlayer/skills/blob/ca7c8088db69e315a8b2deea43820270457f8f3c/plugins/design-control-loop/skills/design-control-loop/SKILL.md)。
