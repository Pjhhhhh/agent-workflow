# 防编造与范围核查

来源、权限与回修规则见技能自带的[执行、核验与恢复](../skills/work-eval/references/execution-and-recovery.md)。

核查时同时读取原始要求、有效纠正、当前交付物及实际检查结果；下列入口分别处理结论依据、操作授权和发现问题后的恢复。

- [主张核查](../skills/work-eval/references/execution-and-recovery.md#主张核查)：对照关键结论、实际检查与来源正文，核对对象、时间、版本和验证层级。
- [范围核查](../skills/work-eval/references/execution-and-recovery.md#范围核查)：对照原请求与授权、实际差异和日志，核对实质操作及精确目标。
- [回修与跨轮恢复](../skills/work-eval/references/execution-and-recovery.md#回修与跨轮恢复)：处理失败、缺证、评审分歧及已确认漏检，修复并复验受影响结果。
