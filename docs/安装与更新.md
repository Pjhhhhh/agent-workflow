# 安装、更新与退出

当前为实验版。推荐使用 `npx skills add Pjhhhhh/agent-workflow --skill work-eval`，或复制整个 `skills/work-eval` 到客户端技能目录。已验证 macOS 上的 Codex CLI；Python 脚本要求 Python 3.9+，仅用标准库。下列链接命令适用于 macOS/Linux 的 POSIX shell；Windows、其他宿主与自动门禁尚未验证。无需 Node、Graphify 或绘图工具即可使用验收器和已有流程图。

## 先试运行

下载并解压完整项目，进入项目根目录：

```sh
python3 examples/run_demo.py
python3 scripts/verify_protocol.py
```

前者生成一个明确标为合成自检的示例，依次核对 provisional 与工件变化后的 partial；后者运行119项协议回放。均只在当前目录 `.codex/verification/` 新建记录，不配置客户端、不访问网络。详细输出见[示例说明](../examples/README.md)。

## 安装技能入口

技能目录自包含；不能仅复制 SKILL.md 而遗漏 references 与 scripts。希望直接使用本地维护源码时，可以采用下面的符号链接方式。以下命令在完整项目根执行；已存在同名目录或链接时停止，先检查原安装，不覆盖：

```sh
workflow_source="$(pwd -P)"
if [ ! -f "$workflow_source/skills/work-eval/SKILL.md" ]; then
  echo '请先进入完整项目根目录'
elif [ -e "$HOME/.agents/skills/work-eval" ] || [ -L "$HOME/.agents/skills/work-eval" ]; then
  echo '已有 work-eval，请核对当前链接或目录，不覆盖'
else
  mkdir -p "$HOME/.agents/skills"
  ln -s "$workflow_source/skills/work-eval" "$HOME/.agents/skills/work-eval"
fi
```

显式要求 Codex 读取 `~/.agents/skills/work-eval/SKILL.md` 即可试用。需要成为默认方式时，在自己的 `~/.codex/AGENTS.md` 合适位置合并下段，保留已有约定，不用本项目 AGENTS.md 覆盖它：

> 处理代码开发、文档修改填写、电脑操作或资料研究时，读取 ~/.agents/skills/work-eval/SKILL.md，按其简单任务、复杂验收和只读委派分支执行；纯问答与状态查询直接回答。任务记录留在实际工作区，沿用目标项目的权限和测试约定，图集按需使用。

若项目存在旧 work-eval 路径、五维总分或固定评审角色要求，先按有效授权协调项目规则。安装不自动注册角色、hooks、服务或外部连接。

## 更新后怎样生效

| 修改对象 | 更新完成时应告知的操作 |
| --- | --- |
| Python 脚本 | 下一次新进程调用使用新版；已运行的进程与旧报告不变 |
| 技能正文、流程参考 | 让相关会话实际重读；检测到技能变化不代表当前任务已采用新正文 |
| AGENTS.md | 当前任务可显式重读；重启 Codex 可重新构建启动指令链 |
| config.toml、技能启停或运行组件 | 重启并核对相关配置；未验证的热加载行为保持未知 |

每次更新交付都说明“无需重启／建议重启／需要重启”的原因及已验证范围。重启前保存当前计划、未完成项与证据，恢复后核对真实文件；不从头重复未受影响的工作。官方说明：[AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md)、[技能](https://learn.chatgpt.com/docs/build-skills)。

可向正在工作的会话发送：

> 请重新读取当前项目有效 AGENTS.md、~/.agents/skills/work-eval/SKILL.md 和相关参考。沿用原任务及授权，核对新规则影响的未完成项和验收，简述变化后继续；不要重做未受影响部分。

## 退出使用

从用户级规则中移除自己添加的默认工作流条目，保留其他约定。核对 `~/.agents/skills/work-eval` 的实际类型与目标；若为上述安装创建的符号链接，仅移除该链接，不删除源码目录或任务证据。若是既有真实目录，不按链接卸载步骤处理。重启 Codex 后核对有效规则与技能发现；没有安装 hooks 或角色就无需清理它们。
