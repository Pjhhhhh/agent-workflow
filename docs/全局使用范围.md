# 全局使用范围

宿主全局规则承载通用行为与按需入口，用户级文档规范约束写作，技能提供任务流程，业务工作区保存任务文件与记录。安装方式见[安装与更新](安装与更新.md)。

## 入口和维护位置

| 对象 | 位置与作用 |
| --- | --- |
| 全局规则 | 由宿主指定并加载，保存通用表达、职责、权限及按任务读取入口；Codex 用户级 `~/.codex/AGENTS.md` 是一个示例 |
| 文档规范 | 按宿主或项目规则读取用户已配置的规范，位置与适用范围由该配置确定；技能不捆绑安装规范 |
| work-eval | 实质任务的执行、核验与恢复流程，源码见[SKILL.md](../skills/work-eval/SKILL.md)及其参考和脚本 |
| doc-maintenance | 处理文档任务，源码见[SKILL.md](../skills/doc-maintenance/SKILL.md)，按适用规范编写或核对正文 |
| 技能安装位置 | 以宿主实际技能目录为准；`~/.agents/skills/<技能名>` 是支持该约定的客户端示例，源码链接可指向本地对应技能目录 |
| 业务工作区与记录 | 位置按[主技能的位置规则](../skills/work-eval/SKILL.md#区分技能位置与任务位置)和目标项目约定；已有必要记录足够时沿用，需要独立运行记录时再单独保存 |

技能目录提供说明与工具，业务工作区承载当前任务；执行采用目标项目的有效规则和当前授权。

源码符号链接让后续读取使用当前源文件；已加载的会话需重读受影响内容。移动源码后更新链接，安装或更新后的实际调用按[最小验收](安装与更新.md#安装后的最小验收)确认。

## 默认分流

- 纯问答与状态查询：遵守已加载的全局规则直接回答。
- 简单实质任务：执行、核验并保留必要终态证据，沿用足够的已有记录。
- 复杂任务或关键证据冲突：沿用计划与必要证据，按风险和依赖完成验证；必要时独立复核，可修缺口继续处理。
- 文档任务：按宿主或项目规则读取适用规范，并使用 doc-maintenance；局部处理与集中整理按请求范围展开。
- 只读委派：按父任务约定返回结果，不递归建立评审链。

完整分流与核验要求见[work-eval](../skills/work-eval/SKILL.md)，文档任务流程见[doc-maintenance](../skills/doc-maintenance/SKILL.md)。自检与独立复核分别核对，明确要求的复核不可用时保留具体缺口。

## 记录检查与 Stop 实验

记录检查 CLI 为显式选用工具，Stop/hook 仅供维护项目内明确授权的实验；命令、独立运行目录和结果含义见[功能入口](../skills/work-eval/references/cli-reference.md)。
