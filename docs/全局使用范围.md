# 全局使用范围

宿主全局规则承载通用行为与按需入口，用户级文档规范约束写作，技能提供任务流程，业务工作区保存任务文件与记录。安装方式见[安装与更新](安装与更新.md)。

## 入口和维护位置

| 对象 | 位置与作用 |
| --- | --- |
| 全局规则 | 由宿主指定并加载，保存通用表达、职责、权限及按任务读取入口；Codex 用户级 `~/.codex/AGENTS.md` 是一个示例 |
| 文档规范 | 按宿主或项目规则读取用户已配置的规范，位置与适用范围由该配置确定 |
| work-eval | 实质任务的执行、核验与恢复流程，源码见[SKILL.md](../skills/work-eval/SKILL.md)及其参考和脚本 |
| doc-maintenance | 按适用规范编写、修改或审阅文档，集中整理时检查跨页内容与导航，源码见[SKILL.md](../skills/doc-maintenance/SKILL.md) |
| 技能安装位置 | 以宿主实际技能目录为准；`~/.agents/skills/<技能名>` 是支持该约定的客户端示例，源码链接可指向本地对应技能目录 |
| 业务工作区与记录 | 保存到目标项目或已有任务约定的位置，沿用必要记录；采用 work-eval 时，再按其[位置规则](../skills/work-eval/SKILL.md#区分技能位置与任务位置)确定计划及独立运行记录的位置 |

执行采用目标项目的有效规则和当前授权。

## 记录检查与 Stop 实验

记录检查 CLI 为显式选用工具，Stop/hook 仅供维护项目内明确授权的实验；命令、独立运行目录和结果含义见[功能入口](../skills/work-eval/references/cli-reference.md)。
