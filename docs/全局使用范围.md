# 全局使用范围

宿主全局规则承载通用行为与按需入口，用户级文档规范约束写作，技能提供整体任务流程与文档专业处理，业务工作区保存任务文件与记录。安装方式见[安装与更新](安装与更新.md)。

## 入口和维护位置

| 对象 | 位置与作用 |
| --- | --- |
| 全局规则 | 由宿主指定并加载，保存通用表达、职责、权限及按任务读取入口；Codex 用户级 `~/.codex/AGENTS.md` 是一个示例 |
| 文档规范 | 按宿主或项目规则读取用户已配置的规范，位置与适用范围由该配置确定 |
| work-eval | 统筹实质任务的分流、执行协调、验收、复核与恢复，按需接入工程方法和专项验证；源码见[SKILL.md](../skills/work-eval/SKILL.md)及其参考和脚本 |
| doc-maintenance | 按适用规范处理文档内容、组织、表达、格式与阅读路径，源码见[SKILL.md](../skills/doc-maintenance/SKILL.md) |
| 工程与验证技能 | 由目标宿主提供实际已安装版本；选择与适配规则见[Matt Pocock](../skills/work-eval/references/matt-pocock.md)和[pstack](../skills/work-eval/references/pstack.md)，结果进入当前任务验收 |
| 技能安装位置 | 以宿主实际技能目录为准；`~/.agents/skills/<技能名>` 是支持该约定的客户端示例，源码链接可指向本地对应技能目录 |
| 业务工作区与记录 | 保存到目标项目或已有任务约定的位置，沿用必要记录；采用 work-eval 时，再按其[任务位置与记录](../skills/work-eval/references/execution-and-recovery.md#任务位置与记录)确定计划及独立运行记录的位置 |

执行采用目标项目的有效规则和当前授权。

## 跨项目使用

用户级安装让宿主能够在多个项目发现技能，按需读取入口决定哪些任务使用它。项目规则负责本项目的任务位置、测试方式和专项约束；任务文件与证据按业务工作区约定保存。本维护仓库的 `.plan/` 和局部实验规则适用于维护本仓库。

## 记录检查与 Stop 实验

记录检查 CLI 为显式选用工具，Stop/hook 仅供维护项目内明确授权的实验；命令、独立运行目录和结果含义见[功能入口](../skills/work-eval/references/cli-reference.md)。
