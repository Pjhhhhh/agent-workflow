# 问题与失败清单

本页维护影响任务完成、证据判断和操作权限的当前风险，以及对应防线和验证入口。修改验收协议前，先补充受影响的失败条件、预期行为和检查方式；验证结果集中在[验证摘要](验证摘要.md)。

## 需求与实施

| 风险 | 当前要求 | 验证入口 |
| --- | --- | --- |
| 实施者把未确认的实现假设写成业务规则 | 对照原请求、有效问答和明确决定；新增前置条件须有有效需求、必要保障或可追溯约定支持 | [需求确认与实施边界](../skills/work-eval/references/execution-and-recovery.md#需求确认与实施边界)，核对测试和评审采用的同一要求 |
| 局部纠正导致其他已定行为被取消 | 只替换与纠正冲突的决定，保留其他有效要求，并更新受影响任务与验收 | [规格、任务与验收证据](../skills/work-eval/references/matt-pocock.md#规格任务与验收证据) |
| 已定位故障环节，却停在泛泛建议 | 信息不足时补最小判别检查；信息充分且已授权时执行具体修复，复验原故障与业务路径 | [工程诊断适配](../skills/work-eval/references/matt-pocock.md#工程诊断适配) |
| 为避免新增限制而遗漏必要保障 | 根据具体失败履行已有权限、数据和安全义务，清楚呈现失败与恢复条件 | [执行、核验与恢复](../skills/work-eval/references/execution-and-recovery.md) |

## 完整验收与评审

| 风险 | 当前要求 | 验证入口 |
| --- | --- | --- |
| 只检查任务清单，遗漏原请求中的必要结果或失败例 | 执行与评审分别对照原要求、有效纠正和专项必要要求，补齐漏项 | [主张核查](../skills/work-eval/references/execution-and-recovery.md#主张核查)；协议回放的 coverage 案例 |
| 结构、引用或命令通过被扩大为内容目标完成 | 按检查对象限定结论；文档内容以实际成稿与读者任务核验，功能以真实终态核验 | [工作流程](工作流程.md#各类任务的验收对象) |
| 局部通过、自检或高分掩盖必要失败 | 必要失败、缺证和独立性分别判定；CLI 不使用评分权重，自检最高为 provisional | [检查状态与恢复](../skills/work-eval/references/record-checking-protocol.md#检查状态与恢复)；完整协议回放 |
| 缺口被直接当作停止理由，或错误判据被悄然降低 | 继续可推进的必要工作；判据确需更正时核实原要求、证据门槛和结论范围，保留更正依据 | [判据更正](../skills/work-eval/references/execution-and-recovery.md#判据更正) |
| 局部反例修复后，同类漏检和原通过结论未复核 | 核实反例对应要求及对象，复查受影响结论和同类原因，修复并复验 | [回修与跨轮恢复](../skills/work-eval/references/execution-and-recovery.md#回修与跨轮恢复) |
| 复审只看新增行，或反复报告已解决问题 | 读取必要调用及保护分支，区分首轮漏报、新回归、误报和重复发现，复用有效证据 | [代码复审](../skills/work-eval/references/execution-and-recovery.md#代码复审)；[真实任务审查案例](真实任务检验.md#审查案例) |

## 主张、来源与操作范围

| 风险 | 当前要求 | 验证入口 |
| --- | --- | --- |
| 原请求、路径别名、符号链接或硬链接被当作完成证据 | 原请求说明要求与授权；必要结果、主张、真实性和范围核查使用独立的实际证据，按同一文件身份排除冒用 | `work_eval.py` 的 `non_request_file()` 与 `evidence()`；协议回放的四条证据通道及路径别名案例 |
| 推断冒充事实、反证冲突或必要结论缺来源 | 区分 fact / inference / unknown，引用支持结论的正文；必要未知保留具体动作 | [关键主张与范围核查](../skills/work-eval/references/record-checking-protocol.md#关键主张与范围核查)；claims 回放 |
| 引文不存在、行号错误、来源未声明或无法按 UTF-8 读取 | 脚本检查已声明来源、行号与单行引文；非文本工件引用实际提取或渲染核验记录 | [输入协议](../skills/work-eval/references/record-checking-protocol.md)；引文及非 UTF-8 回放 |
| 有效引文被当成语义正确或来源可信的证明 | 评审者直接核对来源正文、实际结果和清单外主张，按结论选择必要证据层级 | [主张核查](../skills/work-eval/references/execution-and-recovery.md#主张核查) |
| 核查清单遗漏实际副作用，或操作越过授权 | 对照原请求、实际差异和工具日志，核对操作与精确目标；CLI 比对已声明的允许操作和实际操作 | [范围核查](../skills/work-eval/references/execution-and-recovery.md#范围核查)；scope 与授权引文回放 |
| 任意 unknown 都触发无关文件核对 | 下一动作对应具体缺口；声明工件缺失或不是文件时使用 binding，现场未验证继续对应验证 | 缺失文件、现场未验证及混合缺口回放 |
| 当前记录检查被误认为自动检测全部并发变化 | 检查当前文件与已提交记录；已知外部修改或并发变化影响结论时，复验受影响内容 | [输入协议](../skills/work-eval/references/record-checking-protocol.md#关键主张与范围核查) |

## 文档与既有文件

| 风险 | 当前要求 | 验证入口 |
| --- | --- | --- |
| 整体工作流取代文档专业处理，或两项技能重复主流程 | work-eval 负责统筹，doc-maintenance 负责内容、组织、表达、格式与阅读路径 | [文档任务怎样处理](工作流程.md#文档任务怎样处理)，独立阅读最终入口与相关正文 |
| 当前说明保留 AI 修改经过、临时开发阶段或废弃选择 | 正文只写当前有效用途、行为、必要条件与真实状态；编辑和选型经过留在任务材料中 | 按最终成稿逐段核对用途、时态与依据 |
| 文件级授权被扩大为任意结构或格式改动 | 对照当前基线与原模板，分别核对内容、格式、结构、公式、可读性和可编辑性 | [文件编辑与交付](../skills/doc-maintenance/references/file-editing.md) |
| 局部显示适配越界，或真实冲突直到交付才发现 | 已授权适配核验受影响属性；原属性与显示无法兼得时提出具体取舍，只暂停依赖部分 | [局部版式适配](../skills/doc-maintenance/references/file-editing.md#局部版式适配) |
| 全页审阅漏掉跨页重复、缺口或用途错位 | 按读者任务和阅读路径核对全部要求涉及的文档，重要整理增加成稿读者检查 | [doc-maintenance](../skills/doc-maintenance/SKILL.md#按需集中整理) |

## 运行隔离与恢复

| 风险 | 当前要求 | 验证入口 |
| --- | --- | --- |
| 不同输入或并发写入混合 JSON 与 Markdown 报告 | 不同验收轮使用独立目录；报告通过 `contract_path` 归属及目录锁防止混写；遗留锁按权限处理 | [检查已提交记录](../skills/work-eval/references/cli-reference.md#检查已提交记录)；报告隔离回放 |
| 中断或重试重复产生持久副作用 | 明确同一逻辑操作的重试预期，复用现有事务、去重或检查点，无法安全重试时保留恢复条件 | [后台执行与恢复](../skills/work-eval/references/execution-and-recovery.md#后台执行与恢复) |
| 并行任务冲突写入，或恢复丢失有效要求与未完成项 | 可分离状态优先分离，共享目标明确写入归属；恢复直接核对原任务与当前工件 | [工具选用与协作](../skills/work-eval/SKILL.md#工具选用与协作)与[任务跟踪](agents/issue-tracker.md) |
| 只按步骤数分流，遗漏高影响或复杂依赖 | 按风险、依赖和终态可核验性分流；用户或项目要求的独立复核继续执行 | [任务分支](../skills/work-eval/SKILL.md#先判断任务分支) |

## 协议、安装与局部 Stop 实验

| 风险 | 当前要求 | 验证入口 |
| --- | --- | --- |
| 畸形字段、重复 ID、保留 ID 冲突或非有限 JSON 值进入状态判断 | 字段及类型错误明确报错，正常状态按必要结果和证据决定 | [输入协议](../skills/work-eval/references/record-checking-protocol.md)；score 分组回放 |
| 兼容输入绕过新检查 | 新输入使用 schema 4；schema 2/3 按支持字段读取，缺少必要核查保留具体缺口 | [旧版输入](../skills/work-eval/references/record-checking-protocol.md#旧版输入)；兼容回放 |
| 独立安装后必需参考缺失，或误启用维护仓库门禁 | 必需资料随技能分发；arm 要求维护根标记与标准源码布局，非维护范围 hook 跳过 | installed 分组回放及[独立安装说明](安装与更新.md#可选安装方式) |
| 普通任务误用 Stop 续跑上限，或旧会话拦截无关请求 | 通用任务继续处理必要缺口；局部实验只匹配已登记的当前会话与轮次，恢复实验显式重新 arm | [Stop 实验](../skills/work-eval/references/cli-reference.md#维护项目内的-stop-实验)；hook 分组回放 |
| 分组回放遗漏案例，或帮助与参数解析产生副作用 | 默认 all；score、hook、installed 只运行对应范围及必要前置；导入、帮助和非法参数不创建运行目录 | [重放协议](维护说明.md#重放协议) |
| 技能被发现或规则被加载，被当成真实任务效果 | 分别核对实际路径、宿主发现、正文读取和实际执行；完成率与成本通过固定任务比较 | [最小验收](安装与更新.md#安装后的最小验收)与[真实任务检验](真实任务检验.md) |

协议行为使用 `python3 scripts/verify_protocol.py` 黑盒回放；规则含义、来源语义与文档内容按表中入口核对实际对象。新增风险采用相同结构填写，不以回放通过替代尚未执行的业务验收。
