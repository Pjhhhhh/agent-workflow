# 维护与验证

流程、技能、可选角色模板和源码在本项目维护。安装、更新、卸载和何时重启见[安装与更新](安装与更新.md)。更新交付必须写明是否需要重读或重启，并说明实际核验范围；文件修改不证明在途会话已采用新规则。

## 文件归属

README提供安装和使用入口；技能必需资料放在skills/work-eval内，docs保存按需阅读的项目说明。提交前只暂存核对过的源码、文档、例子和图集，并检查实际Git差异。`.plan/` 保存维护计划，`.codex/` 保存任务、验证、备份和日志，`.playwright-cli/` 保存浏览器观察；它们不属于公开素材。Graphify 的本地输出与历史快照也不在本次发布范围。

每次任务验收使用启动目录 `.codex/verification/<task_id>/<唯一run_id>/`，保留历史输入和判断。需要展示真实案例时只公开脱敏结论与验证边界，不复制用户文档、会话和配置。

## 发布清单自检

维护者在本机准备公开文件时，运行只读检查：

```sh
python3 scripts/verify_release.py --root . --manifest release-files.txt
```

`release-files.txt` 是维护者本机发布准备清单，不随仓库交付，也不是安装依赖；其他使用者可传自己的清单，相对清单路径按 `--root` 解析。清单使用 UTF-8，一行一个相对 `--root` 的文件路径，空行和 `#` 开头的整行注释忽略。检查清单文件是否存在、Markdown 本地文件引用是否纳入清单，拒绝根目录外的路径；中文与空格路径可用。输出 JSON 可由调用者保存，退出码 0 表示通过、1 表示清单或引用缺陷、2 表示参数或读取错误。它不检查锚点、远端安装或模型效果，也不生成分发副本、安装或发布。

先进入项目根目录，执行：

```sh

```

## 更新图

图源 JSON 在 docs/diagrams/specs/，作者为 Pjh；依赖已安装的 Archify 2.17 与 Node，项目不打包上游生成器。以下命令将 `ARCHIFY_CLI` 设置为你本机安装包的 bin/archify.mjs 的绝对路径，然后从项目根运行：

```sh
node "$ARCHIFY_CLI" validate workflow docs/diagrams/specs/05-local-evaluation.json --quality showcase --json
node "$ARCHIFY_CLI" deliver workflow docs/diagrams/specs/05-local-evaluation.json docs/diagrams/05-local-evaluation.html --quality showcase --json
```

deliver 成功后，复制精确 HTML 到启动目录 .codex 的证据目录，确认 SHA256 一致，再对复制文件执行 `visual-check`。浏览器侧车留在证据目录，避免私人绝对路径进入项目；当前四张流程图的 HTML 不需要 Node 或联网即可打开；代码关系图的上游查看器可能加载外部库，另以实际浏览器记录为准。

图的检查包括结构、浏览器运行与布局、实际截图三个部分。结构检查通过后，仍需核对后两部分。已有浏览器检查覆盖 1440×900、1600×1000、1920×1080、2048×1320 及浅深主题；报告保留 visualReview=pending，实际视觉复核另有记录。

## 后续试验

日常分流见 [默认工作流技能](../skills/work-eval/SKILL.md)，运行目录和恢复见 [任务跟踪约定](agents/issue-tracker.md)。四类真实任务先选用户认可的成功/失败样例，固定输入和环境，记录必要项、漏项、返工、催促、耗时；CLI 回放通过不能证明模型早停已经解决。当前协议项数、结果及对应源码哈希见[验证摘要](验证摘要.md)，修改后须重新核对。

用户已授权安装通用默认技能；本次推广没有安装全局 hooks 或角色。未来若要接入原生钩子，先单独验证宿主确实支持项目范围、事件字段、退出规则和路径写权限；没有这一证据时继续手动运行。

维护验证入口时，先判断问题来自说明过期、工具无法观察，还是产品本身出错，再修对应文档、工具或产品，并保留证据。功能变化或真实失败时进行维护；每日自动任务需由用户提出。恢复任务时沿用原计划与验收记录。

同一规则以相关协议或说明为准，入口文件引用它，避免维护多份相同正文。单次轨迹与偶发错误留在任务记录；多次真实案例支持的经验再合并到对应局部说明，写明来源、适用条件与失效条件。这采用 HumanLayer 的单一规则来源与稳定反馈方法，不另建记忆系统。[原始技能](https://github.com/humanlayer/skills/blob/ca7c8088db69e315a8b2deea43820270457f8f3c/plugins/build-iterated-agentic-loop/skills/build-iterated-agentic-loop/SKILL.md)
